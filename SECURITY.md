# Security policy

bagx reads bag files, which may come from untrusted sources. Crashes on malformed input are
bugs and can go through normal issues. If you find something with security impact, such as
arbitrary code execution, path traversal or unbounded resource use from a crafted bag or
rules file, report it privately via GitHub's
[security advisories](https://github.com/rsasaki0109/bagx/security/advisories/new) instead
of a public issue.

Only the latest release is supported with fixes.
